Welcome to your Debian Cloud Desktop

This is a real XFCE X11 session served by KasmVNC and reachable privately through Tailscale. Google Chrome, a terminal, the file manager and a systemd-compatible service layer are installed. Use it like a normal Debian workstation.

Debian 13 XFCE Google Chrome KasmVNC Tailscale Supervisor systemctl D-Bus facade

Quick start

  • Double-click Google Chrome to browse the web.
  • Open Terminal for a shell.
  • Use Systemd Compatibility Info to inspect the service layer.
  • Change the Linux password with sudo passwd desktop.

Access

The desktop is reachable only through Tailscale. Link the node from the public control page, then open the Tailscale IP shown there. The VNC user is desktop; its password is set by the deployment operator through VNC_PW.

Linux user: desktop. The account is in the sudo group. Set or change its password from a terminal with sudo passwd desktop; the current password is supplied privately by the operator, never on this page.

systemd layer

Supervisor is PID 1 and the compatibility layer exposes the usual interfaces: 

systemctl status
systemctl is-system-running
systemctl list-units --type=service
systemd-detect-virt
hostnamectl
journalctl -n 30

This is a compatibility facade, not the real systemd PID 1. It is designed for desktop applications that check the standard interfaces; it is not a security boundary.

Files and storage

Your home directory is /home/desktop. Files are stored in the container and may be lost if the app is redeployed or deleted. Download important files to your own computer.

Security

Use a strong VNC_PW, keep the public control URL private, and avoid storing secrets in the desktop. The public endpoint is protected by HTTPS; the desktop itself is exposed only to your tailnet, and KasmVNC still requires its Basic Auth credentials.
